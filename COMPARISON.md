**Reading it.** A′ matches B on what reaches the model, because a person wrote three tools for this one task and filtered the fields by hand. B's REST call count is one higher than A's because the graph fetches the campaign again for `AccountOwner`. The difference between A′ and B is where the rules live. In A′ they are in one server's Python, for one agent. In B the joins are in the schema, the field rules are `@requiresScopes` in the schema, and the router enforces them for every client, including one that skips the MCP server and calls the graph directly with the same token.
